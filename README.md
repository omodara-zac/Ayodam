# AYODAM PROSPERITY Website

A responsive business website developed for **AYODAM PROSPERITY**, a Nigerian business focused on cement distribution, building materials, and related services.

The website provides visitors with information about the business, its products and services, outlet locations, and ways to get in touch.

## Live Website

Visit the deployed website: https://ayodam.vercel.app/

## Features

- Responsive homepage design
- Business introduction and overview
- Cement and building materials showcase
- Business services and information
- Outlet locations across Ibadan
- Dedicated Contact page
- WhatsApp and telephone contact links
- Responsive navigation
- Scroll animations and interactive elements

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- React Router DOM
- Bootstrap Icons

## Deployment

The website is deployed and publicly accessible.
